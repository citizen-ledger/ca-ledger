AS FILED — UNRECONCILED
THIS LAYER IS AS FILED — UNRECONCILED. THE STATE CONTROLLER PUBLISHES AN ANNUAL TOTAL IN A PRESS RELEASE, BUT THIS EXPORT IS A LIVE DATABASE WITH NO AS-OF-DATE TOTAL, SO THE TWO CANNOT BE ALIGNED AT ANY INSTANT. THIS IS NOT A GATE THAT FAILED; THERE IS NO INSTANT AT WHICH A GATE COULD BE APPLIED. THE OPEN SQUARE MARKS THIS TIER; A FILLED MARK ELSEWHERE ON THE LEDGER MEANS RECONCILED.
