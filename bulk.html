THE PUBLIC RECORD · BULK DATA

Bulk data

Every published layer as one complete CSV — every entity, every shipped year. Each file carries its own source, accounting basis, gate tier and generation date in its header, so it can be read a year from now by someone who never visited this site. The column-by-column schema is bulk/SCHEMA.md.

These are plain files at fixed paths. There is no API, no key, no account, and no rate limit — the same architecture as the rest of the site. Download them, script against them, mirror them.

Three things before you use these

READ THIS FIRST — IT CHANGES YOUR TOTALS An empty cell is not a zeroEvery file carries figures that are absent because the source does not publish them — a district that did not file, a year outside a campus's coverage, a department whose actuals have not arrived. An empty cell means not published. A real reported zero is written 0. A spreadsheet that treats both as zero will produce totals no government ever reported. The layers do not add upThe same dollar appears in more than one file: roughly half of what counties and school districts report receiving is money the state budget already shows sending. There is no combined total, and summing across files produces a number that describes nothing. Bases and tiers differ per fileAn enacted appropriation is a plan; an actual expenditure is a record; an audited GAAP figure is a third thing. And a gated figure reproduces a total its source published, while an as-filed figure has no published control to check against. Both are in this set. Each file's header names its own.

The files

One per published layer. Row and column counts are generated with the files, not typed here.

What is stable, and what is not

The shape of these files is not stable, and this page will not pretend otherwise. The Ledger is actively developed. Columns get added when a layer gains a dimension, renamed when a name turns out to be wrong, and split when one column was carrying two meanings. A script that reads these files by column position will break. Read by column name, and pin a copy of the file if you need a result you can reproduce later.

Nothing here is a deprecation policy, because a two-person-scale project that promised one would break the promise. What the site does instead is record every change it makes to published figures in the record of changes, and keep the reasoning for each layer's shape in its finding document.

That caveat is about shape, not licence. The data is CC0 1.0 — public domain. Use it for anything, commercially or not, with no permission and no attribution required. A link back is welcome because it lets a reader check the figures, not because it is owed. The code is Apache 2.0; the name is neither, so a fork cannot present its own figures as this record.

Checking these against the source

Nothing here asks to be taken on trust. Each file is generated by pipeline/build_bulk.py from the same data files the pages read, and those are built by pipelines that each reconcile against a published control before writing anything. The data files carry a SHA-256 digest; pipeline/verify_digest.py recomputes it.

Where a layer is published as filed rather than gated, that is not an oversight and the reason is measured: the findings index records what was tested, what the measurement showed, and what was decided for every layer — including the questions the Ledger investigated and refused to answer. For the sources and the gate itself, see about & method.
